# PCSPK_pcm

Allows to play raw PCM samples using PC Speaker on Windows and Linux.
Pretty much never-completed proof of concept, but with careful tuning it allows to produce "okay" quality music using PC Speaker.
NOTE: Many computers nowadays don't have any PC Speaker hardware built-in or use only poor-quality buzzer. Sometimes it is possible to plug-in real 8om 0.5W speaker instead or (after some filtering) feed the signal into the line-in or some amplifier.

By default supports 8-bit unsigned PCM samples at the specified sample rate.
